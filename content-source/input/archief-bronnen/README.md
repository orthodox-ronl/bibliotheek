# Archief canonieke bronnen

Hier bewaar je een **vervangen** canonieke notatiebron uit de catalogus
(meestal een `.mscz` nadat de leaf op `.mvsa` is overgegaan), zonder die
te verliezen.

Alleen het **bronbestand** zelf — geen SVG, PDF, mp3 of andere
afgeleiden. De bestandsnaam (publicatiestam) zegt welk catalogus-id
het was, bijvoorbeeld
`cherubijnenhymne-15e-bortnjanski-hemelum.mscz`.

Deze map staat **in git** (niet verwarren met lokale `.archief/`-mappen
die git negeert).
