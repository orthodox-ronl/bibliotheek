Wat heb je nodig

Snel (als je het al eens deed)

  1. Installeer de programma’s uit de tabel hieronder (minstens: Git, Python 3.14, Hugo Extended, MuseScore 4, ffmpeg).
  2. Zet de mappen uit PATH op je gebruikers-PATH; controleer met where.
  3. Zorg dat de map bibliotheek staat onder C:\Git\orthodox-ronl\.
  4. Open Verkenner, ga naar C:\Git\orthodox-ronl\bibliotheek, typ cmd in de adresbalk, druk Enter.
  5. Controletest: check (moet zonder “not found on PATH” eindigen). Lokale preview: serve → http://127.0.0.1:18732/

Wat je nu doet: je pc zo inrichten dat de rest van deze handleiding neerkomt op copy-paste in het Windows-opdrachtvenster, zonder zoeken naar paden.

Je schrijft geen Python-programma’s. Je plakt kant-en-klare regels. MuseScore bedien je met de muis. Org-conventie voor scripts en PATH (technischer): repo-scripts in bron .

Installeren (Windows)

Doe dit eenmaal per pc. Na elke installatie: opdrachtvenster nieuw openen (oude vensters kennen nieuwe PATH-regels niet).

Git

  1. Download Git for Windows en installeer met de standaardopties.
  2. Laat de installer “Git from the command line” / PATH aanpassen aanstaan.
  3. Controle in een nieuw cmd-venster:
where git
git --version

Verwacht: een pad onder bijvoorbeeld C:\Program Files\Git\cmd\ en een versienummer. Geen where-regel → Git staat niet op PATH; herinstalleer of voeg C:\Program Files\Git\cmd toe (zie PATH ).

Python 3.14

  1. Download Python 3.14 van python.org (niet de Microsoft Store-app).
  2. Installeer bij voorkeur naar C:\Python314\.
  3. Vink tijdens de setup Add python.exe to PATH aan, of zet zelf C:\Python314\ én C:\Python314\Scripts\ op PATH.
  4. Controle:
where python
python --version

Verwacht: where wijst naar C:\Python314\python.exe (of vergelijkbaar), niet naar ...\WindowsApps\python.exe. Versie: Python 3.14.x. Staat WindowsApps vooraan? Zet C:\Python314\ hoger in PATH of verwijder de Store-aliassen.

Hugo Extended 0.160.1

  1. Download de extended-build voor Windows van de Hugo-releases (bestand met extended en windows in de naam), versie 0.160.1.
  2. Pak uit naar bijvoorbeeld C:\Git\tools\hugo\ zodat hugo.exe daar staat.
  3. Zet die map op PATH.
  4. Controle:
where hugo
hugo version

Verwacht: het woord extended in de versieregel, en v0.160.1.

MuseScore 4

  1. Installeer vanaf musescore.org (versie 4).
  2. Standaardpad: C:\Program Files\MuseScore 4\bin\MuseScore4.exe.
  3. De tooling vindt MuseScore daar vaak automatisch. Handig op PATH (optioneel): C:\Program Files\MuseScore 4\bin.
  4. Controle (optioneel):
where MuseScore4

Geen where-treffer is geen probleem zolang het bestand onder Program Files\MuseScore 4\ staat. Foutmelding “MuseScore niet gevonden” → Als het misgaat .

ffmpeg

Nodig voor preview-audio (products --kinds audio / Beluisteren). MuseScore maakt het geluid; ffmpeg knipt de nutteloze stilte aan het eind van het .mp3 weg (anders hoor je vaak nog een stuk stilte na de laatste noot).

  1. Download een Windows-build (bijvoorbeeld “ffmpeg full” van gyan.dev ), of via winget install ffmpeg als je winget gebruikt.
  2. Zorg dat ffmpeg.exe op PATH staat (vaak de map bin in de uitpaklocatie).
  3. Controle:
where ffmpeg
ffmpeg -version

Verwacht: een pad naar ffmpeg.exe en een versiekop. Zonder ffmpeg faalt audio-export met een duidelijke fout over ontbrekende ffmpeg.

Editor (Cursor / VS Code / Kladblok)

  • Cursor of VS Code: handig voor .md / .vsa / .mvsa en git.
  • Kladblok: volstaat voor kleine tekstwijzigingen.
  • MuseScore blijft het programma voor .mscz.

PATH

PATH is de lijst mappen waarin Windows zoekt als je in cmd een programmanaam typt (git, python, hugo, ffmpeg, vsa, check, …) zonder het volledige pad ernaartoe. Zo kun je die namen typen zonder C:\…\programma.exe ervoor.

Wat er op je gebruikers-PATH moet staan

Map op PATHZodat je dit kunt typen
.\scriptscheck, serve, products, validate, … (org-conventie; letterlijk zo)
C:\Python314\ en C:\Python314\Scripts\python, pip
C:\Git\tools\hugo (of jouw Hugo-map)hugo
C:\Git\orthodox-ronl\VSA-tooling\.venv\Scriptsvsa (na eerste _ensure / install in die venv)
Map met ffmpeg.exeffmpeg
C:\Program Files\Git\cmdgit (vaak al gezet door de installer)
Optioneel: C:\Program Files\MuseScore 4\binMuseScore4

De regel .\scripts is bewust relatief. Die werkt alleen goed als het huidige mapje in cmd de repo-root is: C:\Git\orthodox-ronl\bibliotheek. Daarom open je cmd altijd vanuit die map (Verkenner → adresbalk → cmd). Scripts controleren of .\scripts in PATH staat; anders krijg je een duidelijke fout.

Zonder .\scripts op PATH mag je nog steeds vanaf de repo-root scripts\check.cmd typen — langer, maar geldig.

PATH wijzigen op Windows

  1. Druk op Start, typ omgevingsvariabelen, open Omgevingsvariabelen voor dit account bewerken.
  2. Onder “Gebruikersvariabelen” selecteer Path → Bewerken.
  3. Nieuw: plak één map per regel (zie de tabel hierboven).
  4. OK op alle dialogen. Open daarna een nieuw opdrachtvenster.

Het Windows-opdrachtvenster (eenmaal openen)

  1. Open Verkenner.
  2. Ga naar C:\Git\orthodox-ronl\bibliotheek.
  3. Klik in de adresbalk, typ cmd, druk Enter.
  4. Plak commando’s in dat venster.

Plakken: rechtsklik, of Ctrl+V. Druk Enter. Wacht tot de prompt terugkomt. Rode tekst of FAILED → Als het misgaat .

Eerste keer

check

Dat bouwt de site (Hugo) en doet de publicatiecontroles. Ontbreekt Python, Hugo, vsa of .\scripts op PATH, dan stopt _ensure met een korte Nederlandse/Engelse aanwijzing — los dat eerst op (tabel hierboven).

Daarna:

serve

Open in de browser http://127.0.0.1:18732/. Gebruik niet poort 1313 (lokaal gereserveerd) en niet 18731 (VSA-demo).

Laat het venster van serve open zolang je kijkt. Klaar: Ctrl+C.
