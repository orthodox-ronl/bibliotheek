Waarop zoeken? Titel of korte naam van het stuk, het catalogus-id (bijv. tropaar/…/hemelum), of een stukje gezongen tekst.

Spellingvarianten (alleluja/alleluia, Johannes/Joannes) en omgewisselde woorden tellen mee. Zoeken loopt over de uitvoeringsvormen in de catalogus.

Uitgebreide uitleg in de handleiding (eerst hoofdlijnen, daarna de technische specificatie).

bron VSA-tooling GitHub
Handleiding ›Start ›Koormap-blad

Op een slot-pagina (index.md onder koormappen\…) zet je zelf de volgorde, de titels en de uitleg. Muziek haal je uit de catalogus met bieb. Bladindeling voor Download pagina / Print pagina regel je met pdf-…. Titels op het blad zet je met kop — geen HTML.

Lees eerst het model catalogus versus koormap in Catalogus en koormappen . Normatieve details: docs\specs\koormap-paginataal.md in de repository (shortcodes en paginacontract). Hoe de partituur op het scherm eruit moet zien (OSMD, SVG, titels): docs\specs\schermpartituur.md. Pagina-PDF bouwen: pdf .

Spiekbriefje

De middelen

MiddelWaarvoor
biebMuziek (en desgewenst titel of bron) uit de catalogus
kopBladtitel of rubriek (standaard: midden, groot)
witruimteExtra ruimte tussen onderdelen (standaard: middel; ook klein / groot)
pdf-bijelkaarIn de download: dit blok bij voorkeur op één A4
pdf-paginaIn de download: hier begint een nieuw A4-blad

Op het web zie je geen bladscheiding door pdf-pagina; alles staat onder elkaar. Alleen de knoppen Download pagina en Print pagina gebruiken die bladindeling, via het bestand index.md.pdf naast de Markdown.

Muziek uit de catalogus

Alleen muziek (kort, met afsluitende />):

{{< bieb id="ektinia/vrede/hemelum" >}}

Zelfde uitvoeringsvorm, met titel en muziek (blokvorm — openen met >, sluiten met /bieb; de korte vorm hierboven eindigt met />):

{{< bieb id="ektinia/vrede/hemelum" >}}
{{< kop >}}{{< titel >}}{{< /kop >}}
{{< muziek >}}
{{< /bieb >}}

Het id is altijd zangstuk/variant/uitvoeringsvorm (drie lagen, met schuine strepen). Zonder onderdeelnaam betekent de korte bieb hetzelfde als muziek. Binnen een bieb-blok mag je muziek en titel zonder telkens het id te herhalen.

Kopjes op het blad

{{< kop >}}(1a) Vredeslitanie{{< /kop >}}

{{< kop links middel >}}Toon 1{{< /kop >}}

Optioneel bijsturen — alleen deze woorden, hoogstens één uitlijning en één grootte:

SoortWoorden
Uitlijninglinks · midden · rechts
Groottegroot · middel · klein

Zonder knoppen is de standaard midden en groot (typische bladtitel). Een rubriek tussen partituren (zoals «Toon 1») zet je meestal met links en middel.

Gebruik geen <h1 style=…> en geen class-namen zoals koormap-tussenkop. Gewone Markdown-koppen (#, ##) mag je gebruiken voor uitlegtekst; voor de bladtitel en rubrieken tussen partituren: kop.

Witruimte tussen onderdelen

Lege regels tussen shortcodes geven geen zichtbare ruimte. Zet expliciet:

{{< witruimte >}}
{{< witruimte groot >}}

Nederlands en Kerkslavisch op één slot

Gebruik per uitvoeringsvorm de titel in de taal van de lyrics (zoals @title in de .mvsa), daarna de korte bieb (alleen muziek). Geen extra tussenkoppen «Nederlands» / «Kerkslavisch». Voorbeeld:

{{< kop >}}1e Kleine Ektinia{{< /kop >}}

{{< bieb id="ektinia/eerste-kleine/hemelum" >}}

{{< witruimte groot >}}

{{< kop >}}Малая ектения{{< /kop >}}

{{< bieb id="ektinia/eerste-kleine/hemelum-ksl" >}}

Korte bieb met /> volstaat als je geen titel/bron uit de catalogus op de pagina hoeft te trekken. Bij grote stukken (bijv. cherubijnenhymne) begint elke taal op een nieuw blad: {{< pdf-pagina >}} ertussen, geen pdf-bijelkaar.

Bladindeling in de download

Nederlands en Kerkslavisch op één blad:

{{< pdf-bijelkaar >}}
{{< kop >}}(1a) Vredeslitanie{{< /kop >}}
{{< bieb id="ektinia/vrede/hemelum" >}}
{{< bieb id="ektinia/vrede/hemelum-ksl" >}}
{{< /pdf-bijelkaar >}}

Elk op een eigen blad: laat pdf-bijelkaar weg en zet {{< pdf-pagina >}} tussen de twee bieb-regels.

Compositie met rubrieken (zoals alleluia-tonen):

{{< kop >}}(9b) Alleluia{{< /kop >}}

{{< pdf-bijelkaar >}}
{{< kop links middel >}}Toon 1{{< /kop >}}
{{< bieb id="alleluia/9a-toon-1/groningen" >}}
{{< kop links middel >}}Toon 2{{< /kop >}}
{{< bieb id="alleluia/9a-toon-2/groningen" >}}
{{< /pdf-bijelkaar >}}

Na wijzigingen aan shortcodes of volgorde: draai pdf opnieuw voor die slot-pagina, anders blijft de oude download staan.
